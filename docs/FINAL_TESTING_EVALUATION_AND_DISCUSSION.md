8. Evaluation
The testing demonstrated that the system can successfully connect academic data from Moodle with the Learning Journey Assistant processing pipeline.
The system was able to retrieve course, assignment, rubric and grade information from Moodle. This information was then used by the AI processing component to generate structured mastery estimates for individual learning outcomes.
The results were successfully stored and exposed through the backend API.
The React dashboard then used these results to provide student-specific learning information, including average mastery and identified skill gaps.
The Student 1 and Student 2 results also demonstrated that the dashboard can present different learning outcomes for different students rather than displaying a single shared result.
9. Discussion
The testing shows that the main technical integration between Moodle, the backend, AI processing and the frontend is working as intended.
One important outcome of the final test was that the system was evaluated using live data from the integrated Moodle environment rather than only testing isolated components.
The AI results also demonstrate how rubric and grade information can be transformed into more understandable learning information.
For Student 1, the system identified four areas that required improvement. For Student 2, the system identified one achieved area and three areas with partial or insufficient mastery.
This provides the basis for the Learning Journey Assistant to move beyond simply displaying academic grades and instead present information about specific learning areas.
However, the current results should be considered prototype-level mastery estimates, rather than official academic grades. The mastery scores are intended to provide learning guidance and identify areas that may require further attention.
10. Testing Limitations
Although the final integration test passed, several limitations remain.
Limited Assessment Data
The current testing used a small number of students and a limited number of assessment results.
Only two students and one assignment were used for the final live test.
Therefore, the current results are not sufficient to determine how the system would behave with a much larger student population or many different assignments.
Limited Written Feedback
The current test data did not contain substantial written marker feedback.
As a result, the AI evaluation relied mainly on assignment grades and rubric information.
More detailed written feedback could provide additional evidence for future mastery estimation.
Mastery Estimation
The mastery scores generated by the AI are estimates designed to support learning insights.
They should not be interpreted as official academic grades.
Further validation with larger datasets and educator-reviewed examples would be required to evaluate the accuracy and consistency of the mastery estimates.
Multiple Assessments
Progress Trends require results from multiple assessments to provide more meaningful longitudinal information.
The current final test used one assignment, so the dashboard correctly indicates that additional assessment results are required for meaningful progress trends.
Deployment
The final system was tested locally using the Flask development server and the React development server.
Further deployment, security and infrastructure testing would be required before the system could be considered production-ready.
11. Final Evaluation
Overall, the final testing demonstrated that the Learning Journey Assistant prototype successfully connects the major system components.
The system can:
- Retrieve academic information from Moodle
- Retrieve assignment and rubric information
- Retrieve student grades
- Process assessment information using AI
- Generate structured mastery estimates
- Store assessment results
- Provide assessment information through REST APIs
- Process student-specific results in the frontend
- Display learning strengths and gaps through the dashboard
The final end-to-end test confirmed that the system is technically connected and that the generated assessment information can successfully reach the student dashboard.
The prototype therefore provides a working foundation for future improvements in mastery estimation, personalised learning recommendations, larger-scale testing and production deployment.
