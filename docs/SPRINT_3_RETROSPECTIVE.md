# Sprint 3 Retrospective

## Sprint Overview

Sprint 3 focused on progressing the Learning Journey Assistant toward
live data integration, backend connectivity, AI integration, dashboard
integration, and integration testing.

## What Went Well

- Backend and Moodle integration progressed.
- Live API endpoints were developed and connected.
- Dashboard integration progressed toward using backend data.
- AI integration work was started with the live data pipeline.
- Integration testing and documentation activities were initiated.

## What Could Be Improved

- Some work items required changes to their estimates during the sprint.
- Several items were removed or adjusted as the sprint scope changed.
- Dependencies between backend, API, AI, and frontend work created coordination challenges.
- More frequent communication could help identify blockers earlier.

## Action Items

- Confirm API and data requirements before implementation.
- Keep backend and frontend teams aligned when API contracts change.
- Perform integration testing earlier rather than leaving it until the end.
- Review sprint scope and estimates regularly.
- Carry unfinished work into the next sprint with clear ownership.

## Team Check-in / Retro Outcome

The team reviewed Sprint 3 progress, discussed completed work,
scope changes, blockers, and areas for improvement. The retrospective
identified better coordination, earlier integration testing, and
clearer handling of dependencies as priorities for the next sprint.
